Parameters

keyOne key. Optional modifiers (comma separated) and hold in ms.
textType it out. Optional delay in ms between characters.
stepsJSON array of {text} or {codes} entries, each with an optional delay.
screenshotSave the current frame as <name>.png.
recordstart or stop. Optional name.
targetWhich device, matched on name or URL. Only needed with more than one JetKVM tab open.
keepLeave this tab open instead of closing it.

Key names

ArrowsArrowUp ArrowDown ArrowLeft ArrowRight
EditingEnter Escape Tab Space Backspace Delete Insert
PagingHome End PageUp PageDown
FunctionF1 … F12
LettersKeyA … KeyZ
DigitsDigit0 … Digit9
ModifiersControlLeft ShiftLeft AltLeft MetaLeft (and the …Right variants)

Examples

?key=ArrowDown
?key=Delete&modifiers=ControlLeft,AltLeft
?key=F2&target=rack-01
?text=root%0A
?steps=[{"codes":["ArrowDown"],"delay":300},{"codes":["Enter"]}]
?screenshot=bios
?record=start&name=boot    then    ?record=stop

These are KeyboardEvent.code names, so they describe the physical key rather than the character it produces. A name JetKVM doesn't recognise does nothing at all — it logs Key down not mapped in the JetKVM tab's console, which is the place to look if a key seems to be ignored.
